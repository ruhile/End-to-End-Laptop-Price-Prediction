# End-to-End Laptop Price Prediction

An End-to-End Data Science project for predicting laptop prices using machine learning and deploying with Flask.

```
End-to-End-Laptop-Price-Prediction/

├── notebooks/

│   └── 04_model_training.ipynb
│
├── src/
│   ├── preprocessing.py
│   ├── train.py
│   ├── predict.py
│   └── utils.py
│
├── models/
│   ├── model.pkl
│   └── scaler.pkl
│
├── app/
│   ├── app.py
│   ├── templates/
│   │      index.html
│   └── static/
│
├── requirements.txt
├── README.md
└── .gitignore
```
